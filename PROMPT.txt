Задача: OntoGate v2. Реализовать реестр пользователей + роли/тарифы + лимиты.

Ограничения:
- Работать ТОЛЬКО внутри текущей директории (~/ontos_work/ontogit-stack).
- Никаких сетевых действий кроме локальных docker compose.
- Не трогать open-webui-src.
- Не выводить секреты.
- Не создавать мусорные файлы в корне (никаких "CACHED", "exporting", и т.п.). Любые временные файлы — только в /tmp или внутри scripts/.
- В конце: список изменённых файлов + команды проверки.

Требования:
1) usage-writer:
   - Добавить таблицы users и roles/plans (role -> лимиты).
   - Добавить эндпоинты: GET /used/{user_id}, GET /limits/{user_id}, PUT /users/{user_id} (role/active).
2) openai-proxy:
   - При каждом запросе брать user_id из X-Ontogit-User.
   - Перед форвардом (только для /v1/chat/completions) спросить usage-writer used/limits, вычислить warn/block.
   - Если block: вернуть 429 JSON {error:"limit_exceeded", user_id, used_usd, limit_usd} и headers.
   - Всегда добавлять headers X-Ontogit-User, X-Ontogit-Used-USD, X-Ontogit-Limit-USD, X-Ontogit-Warn.
   - /v1/models не блокировать.
3) docker-compose.yml:
   - Прокинуть нужные env между сервисами (USAGE_WRITER_URL уже есть).
   - Добавить переменные для лимитов (можно дефолты в usage-writer roles).
4) scripts/test.sh:
   - Прогон: AUTH_REQUIRED=1, u1/u2 токены, назначить роли, проверить разные лимиты и блок u1 при >= limit.
